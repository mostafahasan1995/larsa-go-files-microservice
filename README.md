# larsa-go-files-microservice

File storage and drive microservice for the Larsa platform.

**Stack:** Go, MongoDB, Redis, NATS

> Built by the Larsa engineering team and published with the company's permission. My contribution: 29 of 290 commits. This is a clean snapshot: git history is removed and secrets are replaced with placeholders.

## Setup

```bash
cp .env.example .env   # then fill in the values
go run .
```
